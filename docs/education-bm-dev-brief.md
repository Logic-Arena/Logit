# Logit Edu BM / Development Brief

이 문서는 팀 공유용으로 만든 교육용 BM 제안서입니다. 시각자료는 아래 두 파일입니다.

- [교육용 BM 개요](./education-bm-overview.svg)
- [선생님 대시보드 와이어프레임](./teacher-dashboard-wireframe.svg)

## 1. 한 줄 정의

Logit Edu는 학생이 AI 토론 과제를 수행하면, AI가 발언을 채점하고 선생님이 학급 전체의 사고력/언어 역량 상태를 관리할 수 있게 해주는 교육용 SaaS입니다.

## 2. 왜 교육용이 맞는가

현재 제품은 이미 AI 토론, AI 훈수, AI 판정, 점수 이력, 성장 차트, 추천 훈련을 갖고 있습니다. 즉 단순 커뮤니티/게임보다 “학습 진단과 지도” 쪽으로 바꾸면 기존 기능의 가치가 더 분명해집니다.

학생 입장에서는 토론 훈련 앱입니다. 선생님 입장에서는 학생별 약점을 빠르게 파악하는 관리 도구입니다. 학교/학원 입장에서는 수행평가, 독서토론, 면접 준비, 논술 수업에 붙일 수 있는 운영 시스템입니다.

## 3. 핵심 역량 지표

초기 MVP에서는 아래 7개 지표를 추천합니다.

- 문해력: 주제와 상대 발언을 정확히 이해했는가
- 어휘력: 적절하고 다양한 단어를 사용했는가
- 논리력: 주장과 근거의 연결이 일관적인가
- 근거력: 사례, 데이터, 출처, 구체적 이유가 있는가
- 공감능력: 상대 입장을 공정하게 요약하고 존중했는가
- 표현력: 문장이 명확하고 전달력이 있는가
- 반박력: 상대 주장에 직접 대응했는가

현재 코드의 `logic`, `evidence`, `persuasion`, `rebuttal`을 확장하면 됩니다. 새 지표를 바로 추가하기 부담스럽다면 MVP 1차는 기존 4개 지표로 시작하고, 교육용 런칭 직전에 문해력/어휘력/공감능력을 추가하는 방식이 안전합니다.

## 4. 선생님 대시보드 MVP

첫 화면에서 선생님이 바로 봐야 하는 것은 네 가지입니다.

- 학급 평균 점수와 최근 성장률
- 지도 필요 학생 목록
- 역량별 히트맵
- 학생별 추천 지도 액션

개별 학생 상세에서는 최근 토론 기록, AI 조언, 약점 원인, 다음 과제를 보여줍니다. 중요한 건 “점수 표시”가 아니라 “다음에 뭘 지도해야 하는지”까지 연결하는 것입니다.

## 5. BM 구조

추천 BM은 무료 파일럿 + 클래스 구독 + 기관 계약입니다.

- 무료 파일럿: 1개 반, 학생 수/월 과제 수 제한
- 클래스 플랜: 선생님 1명 + 학생 seat 기반 월 구독
- 학교/학원 플랜: 여러 반, 관리자 계정, 리포트 export, 커스텀 루브릭
- 부가 상품: 사람 코치 첨삭, 면접 대비 주제팩, 수행평가 리포트

개인 B2C 구독보다 교육기관 B2B/B2B2C가 더 현실적입니다. 토론은 혼자 매일 쓰는 앱이 되기 어렵지만, 선생님이 과제로 배정하면 반복 사용이 생깁니다.

## 6. 개발 모델 제안

현재 `User`, `UserStats`, `DebateHistory` 중심 구조에 교육용 모델을 추가합니다.

```text
Organization
  - 학교, 학원, 동아리, 스터디 그룹

Classroom
  - 반/그룹 단위
  - teacher_id, organization_id

Enrollment
  - student_id, classroom_id, role

Assignment
  - 토론 과제
  - topic, due_at, rubric_id, mode

Rubric
  - 평가 기준
  - 문해력, 어휘력, 논리력, 근거력, 공감능력, 표현력, 반박력

StudentMetric
  - assignment_id, student_id
  - 각 지표 점수, AI summary, teacher note

Subscription / SeatUsage
  - 플랜, 학생 seat, 월 AI 과제 제한
```

## 7. 개발 순서

1. 1인 AI 토론 모드 추가
2. 기존 AI 채점 결과를 확장 가능한 rubric 형태로 저장
3. 선생님/학생 role 구분
4. Classroom, Enrollment, Assignment 모델 추가
5. 선생님 대시보드 API 추가
6. 학생별 상세 리포트 페이지 추가
7. 무료/유료 사용량 제한 추가
8. 결제 또는 기관 계약용 seat 관리 추가

## 8. 팀 논의 포인트

- 초기 타깃을 학교, 학원, 토론 동아리, 면접 스터디 중 어디로 잡을지
- MVP 지표를 기존 4개로 갈지, 교육용 7개로 바로 갈지
- 선생님이 직접 루브릭을 만들 수 있게 할지
- 학생 실명/개인정보를 어떻게 최소화할지
- AI 채점 결과를 선생님이 수정/승인할 수 있게 할지

## 9. 핵심 메시지

이 제품의 수익화 포인트는 “AI 토론 한 판”이 아니라 “선생님이 학생들을 더 잘 지도하게 해주는 데이터와 리포트”입니다. 따라서 개발 우선순위도 게임성보다 학급 관리, 학생별 진단, 과제 배정, 리포트 저장에 둬야 합니다.
